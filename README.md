# SimTX Android

Native Android client for SimTX, built with Kotlin and Jetpack Compose.

> Early foundation: account credentials UI, station workspace, receiver/transmitter control surfaces, and Android CI. Live API operations are only enabled once their exact endpoints and the SimTX v25 TLS/Protocol Buffers wire contract are implemented and verified against the official documentation.

## Build

Open this project in Android Studio (JDK 17, Android SDK 35), or run `./gradlew assembleDebug` after the Gradle wrapper is generated by Android Studio.

## API reference

https://wiki.simtx.net/index.php/SimTX_API

## Security

Never commit credentials or access tokens. Account fields are not persisted by this initial build.
